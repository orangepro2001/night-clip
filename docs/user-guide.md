# ClipBridge 使用说明书

> 适用于本仓库当前版本。ClipBridge 在你自己的 Windows 电脑和 Android 手机之间同步剪贴板文本、传输文件。设备之间通过 Tailscale 直连，**不经过任何第三方服务器**。
> 诚实说明：开发机上没有 Windows 桌面和 Android 真机，两端界面和系统功能（托盘、剪贴板监听、通知、相机扫码、前台服务、MediaStore）已编译并有大量逻辑单测，但**尚未在真机上跑过**。第 12 节列出了建议你优先验证的地方。

## 1. 它能做什么

| 功能 | 说明 |
| --- | --- |
| 剪贴板同步（文本） | 复制即自动广播到所有已配对设备；电脑上复制 → 手机前台时直接写入，否则通知；手机在打开应用时自动发送，也可通过按钮、分享菜单、通知或快捷设置磁贴手动发 |
| 文件传输 | 双向，默认上限 4 GiB，断线自动续传，收齐后校验 SHA-256 才保存 |
| 配对 | 一次性二维码/链接 + 双方核对 6 位数字，之后用证书互相认证 |
| 离线补发 | 对方离线时内容排队，在有效期（默认 15 分钟）内回来会自动补发；过期的丢弃 |
| 自动更新 | 新版本发布后约 1 秒内收到通知并自动下载 |
| 命令行 | Windows 上 `cbridge`，可发送文本/文件、查看状态 |

不做：iOS/macOS/Linux 客户端、图片/富文本剪贴板、云端中转。

## 2. 使用前提

1. 所有要同步的设备都**安装并登录 Tailscale**，处于同一个 tailnet，保持连接。
2. Windows：64 位 Windows 10/11，已装 **.NET 10 桌面运行时（x64）**。
3. Android：8.0（API 26）及以上，64 位 ARM。

## 3. 安装

下载页（设备已连上 tailnet 时用浏览器打开）：`https://tony-ai-pc-1.tail9f7f1f.ts.net/clipbridge/`

**Windows**

1. 下载 zip，右键 → 属性 → 勾选“解除锁定”。
2. 解压到当前用户可写的文件夹（例如 `D:\Apps\ClipBridge\`，不要放 `Program Files`，否则无法自动更新）。
3. 运行 `ClipBridge.exe`。出现 SmartScreen 提示时点“更多信息 → 仍要运行”（程序没有购买代码签名证书）。
4. 首次监听时 Windows 防火墙可能弹窗，选择允许“**专用网络**”。设备之间只通过 Tailscale 地址直连。
5. zip 里还有 `cbridge.exe`（命令行，见第 9 节）。

**Android**

1. 下载 APK 并安装，系统会引导你允许“安装未知应用”。
2. 打开 ClipBridge，按首次引导操作：确认 Tailscale 已连接、允许通知；电池优化是可选项。

## 4. 配对（一次性）

两台设备都在线、都开着 Tailscale。

1. **电脑**：设备页 → “配对新设备…”，窗口显示二维码和配对链接（5 分钟有效）。
2. **手机**：设备页 → “配对新设备”，选一种方式：
   - **扫码**：扫描电脑上的二维码（需要相机权限）；
   - **粘贴链接**：把电脑上“复制链接”得到的 `clipbridge://pair?…` 粘贴进来；
   - **手动输入**：填电脑的 Tailscale 地址、端口、配对密钥（指纹可选；不填时务必核对下一步的数字）。
3. 手机显示一个 **6 位数字**，电脑弹出“配对请求”也显示一个数字。**两个数字必须一致**，再在电脑上点“允许”。不一致就点“拒绝”，不要继续——这说明连接可能被人拦截。
4. 双方显示“配对成功”。之后设备会自动连接，重启后也一样。

电脑之间同理：一台“配对新设备…”，另一台“加入配对…”。

解除配对：设备页 → “解除配对”（会通知对方并永久拉黑对方证书）。

## 5. 同步剪贴板

配对完成后**不需要再设置任何东西**：在任一设备上复制，内容会自动发到所有已配对的设备；对方在线且在前台/可写时直接写进它的剪贴板。（想关掉：电脑托盘菜单里取消“同步我复制的内容”，手机设置里关闭“自动发送我复制的内容”。）

### 电脑 → 其它设备

1. 在电脑上复制文字。电脑一直在监听剪贴板，所以**每次复制都会自动发给所有已配对的设备**（在设备页可以对某台设备关掉“自动发送”，例如只想收不想发的公用电脑）。
2. 对方是电脑：默认直接写入它的剪贴板（写入前会确认你没有在这期间又复制了别的东西，否则只通知）。
3. 对方是手机：应用在前台时直接写入；否则弹“收到的剪贴板”通知，点“复制”写入，点“忽略”丢弃。

### 手机 → 其它设备

Android 不允许应用在后台读取剪贴板，所以自动发送发生在**你打开 ClipBridge 的时候**：窗口获得焦点时检查一次剪贴板，如果有刚复制（5 分钟内）的新内容，就自动发到所有已配对的设备并提示“已发送给 N 台设备”。第一次安装后看到的剪贴板内容只记录、不发送。不想等到打开应用时，仍可以随时手动发：

- 在 ClipBridge 里点“发送剪贴板”；
- 在任何应用里选中文字 → 分享 → ClipBridge；
- 通知栏常驻通知上的“发送剪贴板”；
- 快捷设置磁贴“发送剪贴板”（先把磁贴添加到快捷设置面板）。

### 暂停、撤销与保护

- **暂停同步**：电脑托盘菜单“暂停同步”（15 分钟 / 1 小时 / 4 小时），手机设置里“暂停同步”。暂停期间本机既不自动发送，也不自动写入收到的内容（只通知）；到点自动恢复，也可以随时“恢复同步”。手动发送不受影响。
- **撤销**：电脑自动写入你的剪贴板后，托盘菜单“撤销上次自动写入”在 2 分钟内可以恢复写入前的内容（只保存在内存里，不写磁盘；来自密码管理器的内容不会被保存）。
- **只有刚复制的内容才会自动写入**：对方离线、休眠、网络慢而晚到（超过 20 秒）的内容只通知，不会覆盖你此刻的剪贴板，点“复制”才写入。
- **不会来回弹**：三台及以上设备时，一台设备写入的内容不会被它自己再广播出去，没有时间限制；你真正复制了别的内容之后才重新开始。

### 处理策略（每台设备单独设置）

| 策略 | 效果 |
| --- | --- |
| 只通知 | 弹通知，不改剪贴板 |
| 手动 | 通知，点“复制”后才写入 |
| 自动 | 直接写入剪贴板（**新配对的设备默认**）。电脑端写入前会检查你有没有又复制了别的东西，有则降级为通知；手机端只在应用处于前台时自动写入，否则降级为通知 |

在设备页调整每台设备；设置页可设“新设备的默认策略”。**升级前已经配对的设备保持原来的策略**，想让它们也自动写入，在设备页改成“自动”。

### 敏感内容

看起来像密码、令牌、私钥、一次性验证码的文本会被标记为**敏感**：通知和列表里只显示“敏感内容（已隐藏）”，点“显示”才展开；**永远不会自动写入**，即使策略是“自动”；想完全不发送这类内容，在设置里关闭“允许发送看起来像口令/令牌的内容”。这是启发式判断，可能误判（例如 `Hello123`），误判只会让它不自动写入。

### 其它行为

- 刚写入的内容不会被当作新内容发回去（回声抑制）；一次复制触发多次通知也只发一次。
- 单条文本上限 64 KiB，更大的请作为文件发送。
- 带“排除监控”标记的复制（密码管理器），电脑端会忽略。
- 对方离线时内容排队，过期（默认 15 分钟，设置里可改 30–86400 秒）后丢弃；对方回来时补发的内容只通知、不自动写入。

## 6. 传文件

**发送**：电脑——设备页“发送文件…”选设备和文件（可多选），或把文件拖到设备卡片上；手机——在文件管理器/相册里分享 → ClipBridge，选择目标设备；命令行——`cbridge file send --to 设备名 文件…`。

**接收**：对方发来时弹出提示（文件名、大小、来自谁），**不会自动接收**。点“接收”才开始，“拒绝”则通知对方。进度、速度和取消在“传输”页（手机是通知）。

- 电脑保存到设置里的“接收文件的保存位置”（默认 `下载\ClipBridge`）；重名自动加 `(1)`，不会覆盖已有文件。
- 手机先收到应用私有目录，完成后保存到“下载/ClipBridge”并清理私有副本。
- 断线、重启应用会自动续传；收齐后核对校验和，不一致会删除并提示让对方重发。
- 空间不足时会拒绝，不会去删你的其它文件。
- 对方给的文件名会被清洗（去掉路径、非法字符、Windows 保留名），无法写到保存目录之外。

## 7. 各页面

**电脑**（左侧导航）

- **设备**：已配对设备、状态（已连接 / 正在连接 / 离线（排队 N 条）/ 需要重新配对 / 已解除）、重命名、策略、重新连接、解除配对、发送文件。
- **收件箱**：最近收到的文本，“复制”“忽略”，敏感条目折叠，“清空”。
- **传输**：文件传输的进度与历史。
- **设置**：同步开关、新设备默认策略、有效期、收件箱条数、是否允许发送敏感内容、开机自启、接收文件位置、更新、防火墙说明、关于。
- **诊断**：核心状态、监听地址、各设备游标；“没有找到 Tailscale 地址”横幅；复制诊断信息（不含密钥）、打开日志/数据文件夹。

**托盘**：左键打开窗口；右键菜单有“配对新设备…”“同步我复制的内容”“立即发送当前剪贴板”“开机自启”“检查更新”“退出”。**关闭窗口只是隐藏到托盘**，要退出请用托盘菜单。

**手机**（底部导航）：设备、收件箱、设置。设置里的**实时模式**（默认关）开启后常驻一条通知并保持后台连接，重启手机后自动恢复；关闭时只在应用运行期间同步。建议同时把 ClipBridge 从电池优化中排除，否则部分系统会杀掉后台。

## 8. 更新

- 应用启动后保持与更新服务的连接，开发者一发布新版本，约 1 秒内收到。默认自动下载并校验（签名、大小、SHA-256），关闭“自动下载”后需手动点“下载”。
- **Android**：通知“ClipBridge 更新已就绪”，点按安装（首次需允许“安装未知应用”）。
- **Windows**：托盘气泡 + 任务栏闪烁，点“重启并更新”；安装失败会回滚并继续运行旧版本。
- 实时通知只在应用运行时有效（手机建议开实时模式）。

## 9. 命令行 `cbridge`（Windows）

需要 ClipBridge 正在运行。常用：

```text
cbridge status                          状态与设备
cbridge doctor                          检查 Tailscale 地址、配对和连接
cbridge clip send --text "你好"          发给所有设备（--to 设备名 指定一台；不带 --text 时读标准输入）
cbridge file send --to Pixel a.zip      发文件（--wait 等到完成）
cbridge inbox list | inbox show <id>    查看收件箱（敏感条目的正文只在界面里显示）
cbridge transfers                       传输列表
cbridge --json status                   机器可读输出
```

配对、解除配对、修改设置等涉及信任的操作**只能在界面里做**。详见 [api-spec.md](api-spec.md) §9（含退出码）。

## 10. 数据与隐私

- 数据目录：Windows `%LOCALAPPDATA%\ClipBridge\`；Android 应用私有目录。
- 数据库里的设备私钥、事件内容、剪贴板文本均加密；加密密钥由 Windows DPAPI / Android Keystore 保护（旧版本的明文密钥文件首次启动时自动迁移并删除）。
- 程序不向第三方发送数据；唯一的外联是向你自己的更新服务器检查和下载更新。
- 日志不记录剪贴板内容、配对密钥和密钥。
- **重置本机**：关闭程序，同时删除整个数据目录（Android：系统设置里“清除数据”）。会得到新的设备 ID，所有配对需要重做。**不要只删数据库或只删密钥文件。**

## 11. 常见问题

| 现象 | 处理 |
| --- | --- |
| 电脑显示“没有找到 Tailscale 地址” | Tailscale 未运行/未登录；启动并登录后几秒内自动恢复 |
| 设备一直“正在连接”/“离线” | 两端都要连着 Tailscale；防火墙是否允许“专用网络”；对方应用是否在运行（手机建议开实时模式） |
| 设备显示“需要重新配对” | 对方已不认识本机（被解除或重装）；解除配对后重新配对 |
| 配对时两边数字不一致 | 点“拒绝”，不要继续 |
| 手机收不到内容 | 通知权限是否打开；应用是否被系统杀后台；在设备页看状态 |
| 手机点“复制”没反应 | 少数系统限制后台界面写剪贴板；先打开 ClipBridge 再从收件箱复制 |
| 文件“校验失败” | 传输中文件被改动或损坏，让对方重发 |
| 更新失败 | 设备没连上 tailnet 或开发机离线；连上后手动检查更新 |

## 12. 建议你优先在真机上验证的地方

1. Windows：托盘图标与气泡；复制一次是否只发一次；从密码管理器复制是否被忽略；DPAPI 密钥迁移；防火墙弹窗；开机自启；更新后重启。
2. Android：扫码配对；通知上的“复制”“忽略”；分享菜单与快捷设置磁贴；实时模式在你的手机品牌上锁屏后的存活；接收文件保存到“下载”。
3. 两端：配对 → 双向同步 → 断网/休眠后恢复 → 大文件续传。

## 14. 自动填充（Android，密码库）

> **请先知道：** 自动填充只做过编译和自动化单元测试，**还没有在真机上运行过**。请先用不重要的账号试用，并保留密码库的备份。通行密钥（Passkey）**不在这一阶段**。

**启用：** 在 ClipBridge 的设置里点“启用自动填充”，系统会问“要把 ClipBridge 密码库设为自动填充服务吗？”，选择确定即可（也可以去系统设置 → 密码和账号 → 首选服务）。启用后，在登录页面点用户名或密码输入框，下方会出现要填充的条目。

**怎么用：**

- 密码库已锁定时，弹出一行“解锁以填充”，输入主密码即可，成功后会列出匹配的条目；点一个就填入。
- 最多列出 5 个条目，最匹配的在前；每一行只显示标题和用户名，不显示密码。
- 没有匹配的条目时，只出现一行“打开 ClipBridge 密码库”。
- 页面要求验证码（两步验证）且条目里设置了 TOTP 时，会列出该条目；点选的一刻才生成当前验证码。
- 提交登录后，系统会问是否“保存到密码库”：可以确认或修改标题、用户名、网址再保存；如果同一个账号已有条目但密码不同，会问是否更新（旧密码保留在历史里）。
- 设置里的“每次填充前验证主密码”：开启后每次填充都要重新输入主密码。

**匹配规则：** 网页只按浏览器报告的域名匹配（同一个“主域名”才算，名字相似的不算，比如 `example.com.evil.net` 不会匹配 `example.com`）；应用按包名匹配（条目网址写 `androidapp://包名`，或自定义字段 `AndroidApp`）。`http://` 页面不会填充保存为 `https://` 的条目。浏览器如果没有报告域名，就不会提供任何填充。

**哪些浏览器：** Chrome 135 及以上、Firefox 等直接支持第三方自动填充服务；更老的 Chrome 需要在 Chrome 设置里启用“第三方自动填充”（或系统的兼容模式），否则网页里看不到候选项。ClipBridge 自己的界面不会被填充。应用里嵌入的网页（WebView）每次都会要求输入主密码。

**不做的事：** 不读剪贴板，不使用无障碍服务，不联网，不缓存密码；自绘界面或关闭了自动填充的应用里不会出现候选项。

**还没验证的：** 各品牌系统下下拉框的样子与位置、Chrome/Firefox 是否报告网页协议（`http`/`https`）、保存提示在不同系统版本上的行为、从后台解锁之后的自动上锁时间。遇到问题请告诉我具体的应用或网站。
